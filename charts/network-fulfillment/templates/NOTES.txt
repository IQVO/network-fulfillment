This install talks to NO external network. The stub adapter answers every
call locally, which is why it needs no external configuration. That is the
intended default for local clusters and e2e runs -- an install that reached a
real retailer's API by accident would acknowledge real orders.

To integrate for real, set config.networkMode to "live", config.networkBaseUrl
and config.networkVendorId (the chart refuses to render without them). Live
takes no credential. Add networkNodes.nodes for any site that is not yet a node
